## 📋 安裝說明

<img width="20" height="20" alt="image" src="https://github.com/user-attachments/assets/aabaeee9-c810-4ffe-85db-fb05b8827758" /> 適用PCL
1. 下載整合包檔案
2. 將整合包拖入 `PCL` 啟動器
3. 使用啟動器選取 `by.dddadian01 26.3` 實例並啟動
4. 若有衝突，請檢查 mods 內重複模組

- 文件夾導入
1. 下載 `mods.zip` 檔案
2. 將 `mods.zip` 解壓縮
3. 複製解壓縮後的 `mods` 文件夾
4. 貼上/覆蓋 至 `.minecraft` 路徑中

## ⚠️ 注意事項

- 本整合包基於 Minecraft 26.3，不支援其他版本
- 如自行手動安裝模組，需再確認是否安裝對應前置模組
- 新增 / 移除模組前建議備份
- 若遇到崩潰，可查看遊戲 crash log 除錯
- Litematica Printer All 及 Tweakeroo 有些許功能恐違反伺服器規範，使用前請自行判斷，如遭判定封號請自行負責
